## Labels to use on screen and in speech

- **BASELINE:** existing foundation code and recorded verification; fresh
  operational readiness still needs a passing preview/rehearsal.
- **TEST EVIDENCE:** real executed lane tests with stated doubles/boundaries;
  not a running integrated product.
- **CONDITIONAL:** include only after human review and complete-delivery evidence.
- **CONCEPT:** prepared explanation or answer card, not executed functionality.
- **RECORDING:** an actual supplied recording identified by its date/build/mode.
  None has been located for Sazzle or approved Jev discovery.
- **UNAVAILABLE:** absent, unsupported, unapproved or inaccessible. Never replace
  with a silent fixture result.
